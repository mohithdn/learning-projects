1. Deterministic Logic vs. Probabilistic LLMs

Plain-language explanation: A rule-based chatbot uses deterministic logic. This means for a given input, the output is always predictable and traceable. It doesn't "guess" or "predict" based on statistical patterns like an LLM (Large Language Model) does. It simply looks up keywords in a pre-defined dictionary.

Real-life analogy: Think of a rule-based bot as a vending machine. If you press B4, you get a specific bag of chips. If you press an invalid code, nothing happens (or it gives an error). An LLM is like a chef who tastes the air and decides to make you a custom meal based on what they think you might like.

# The Rule-Based Dictionary
FAQ_DATA = {
    "greeting": {
        "keywords": ["hello", "hi", "hey"],
        "response": "Hello! Welcome to our customer support."
    },
    "pricing": {
        "keywords": ["price", "cost", "how much"],
        "response": "Our standard plan starts at $9.99/month."
    }
}
⚠️ Pitfall: Rule-based systems are brittle. If a user types "Hey there!", it will match "hey" perfectly. But if they type "Greetings, human.", it might fail if "greetings" isn't in the keyword list. Always anticipate synonyms!

2. Text Sanitization (Preprocessing)

Plain-language explanation: Raw user input is messy. It contains extra spaces, inconsistent capitalization, and punctuation. Sanitization is the process of cleaning this raw string so it can be reliably matched against your keywords.

Real-life analogy: Imagine a librarian trying to file a book titled " THE GREAT gatsby?! ". Before filing, they strip the spaces, lowercase everything, and remove the punctuation to get "the great gatsby".

Worked Code Example

import re

def get_bot_response(user_input):
    # 1. Strip whitespace and convert to lowercase
    clean_input = user_input.strip().lower()
    
    # 2. Remove punctuation using Regex
    clean_input_no_punct = re.sub(r'[^\w\s]', '', clean_input)
    
    return clean_input_no_punct
💡 Pro Tip: The regex r'[^\w\s]' is a powerful tool. It translates to "match any character that is NOT a word character (\w) or a whitespace character (\s)". This effectively strips all punctuation.

3. Intent Pattern Matching & Scoring

Plain-language explanation: Once the text is clean, the bot searches for keywords. To handle complex sentences, we use a scoring system. If a user says "How much is the premium plan?", the bot finds "how much" (2 words) and "plan" (1 word). It scores this higher than a generic query like "plan" (1 word), ensuring it routes to the "pricing" intent.

    topic = " ".join(clean_input_no_punct.split()[:4]) + "..."

5. Streamlit Chat UI & State Management

Plain-language explanation: Streamlit reruns the entire Python script from top to bottom every time a user interacts with a widget. To maintain a chat history, we use st.session_state, which is a dictionary that persists across these reruns. We append new messages to a list and re-render the entire chat window.

Real-life analogy: Imagine writing on a whiteboard. Every time someone asks a question, you erase the board and rewrite the entire conversation from your notebook. st.session_state is that notebook.

Worked Code Example

import streamlit as st

# Initialize chat history
if "messages" not in st.session_state:
    st.session_state.messages = [
        {"role": "assistant", "content": "Hi there!"}
    ]

# Display chat messages from history
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# React to user input
if prompt := st.chat_input("Type here..."):
    st.chat_message("user").markdown(prompt)
    st.session_state.messages.append({"role": "user", "content": prompt})
    
    response = get_bot_response(prompt)
    
    with st.chat_message("assistant"):
        st.markdown(response)
    st.session_state.messages.append({"role": "assistant", "content": response})
